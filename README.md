### 🚀 Featured build — Launchpad

**An autonomous career agent** that doesn't just generate AI content on a fixed
schedule — it runs a real Groq tool-calling decision loop, reads your actual
state each cycle (job market activity, network follow-ups, skill gaps), and
decides for itself which of its tools are worth running, in what order.

- 🧠 Agentic decision loop (Groq function calling), not a hardcoded pipeline
- 📊 Job matching, career scoring, skill-gap analysis — all AI-scored against a real profile
- 🤝 Network outreach + LinkedIn contact suggestions, generated per job match
- 📄 Full evidence-based promotion case, pulled from logged achievements
- ✉️ Weekly email brief, sent automatically on a schedule

**Stack:** Next.js 16 · TypeScript · Tailwind · Supabase · Groq · Resend

🔗 **[Live demo](https://launchpad-ashen-six.vercel.app)**
